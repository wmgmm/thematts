COMMENTS
Add comments where an issue needs discussion rather than a direct edit.
Each council member comments from their own point of view. Set each comment's author to that member's role, such as "Expert Editor", so I can see who said what. Start each comment with its type, then write it as a short question for me:
• GAP: a question a reader would ask that the document doesn't answer, such as a missing detail, owner, date or next step.
• CHECK: an inconsistency, where something doesn't match another part of the document (terms, names, dates, figures), or a claim with no evidence.
• RISK: act as a critical friend. Imagine it is a year from now and this document has failed. Why?

Up to 3 comments per member. If two members raise the same point, keep one comment and say who agrees. Never add facts yourself. If something may be wrong or overstated, comment instead of editing.
