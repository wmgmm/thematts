Create a Mermaid mind map of the document I give you, so anyone can check it at a glance.

First, read the whole document.

MIND MAP
• Centre: the document's main purpose, three words or fewer.
• Branches: its 3–6 main themes, fewer for a short document.
• Sub-branches: up to 3 key points per theme, five words or fewer.
• Write every label in plain English a new member of staff would understand.
• Use only what the document says. Never add facts.

FLAGS
Attach each flag to the theme it belongs to, as a short question of five words or fewer. Base each flag on a specific part of the document. Up to 2 flags per theme, with at least one of each type across the map.
• GAP: a question a reader would ask that the document doesn't answer, or a blank left to fill in. Shown as a cloud.
• CHECK: something that doesn't match another part, or a claim with no evidence. Shown as a hexagon.
• RISK: act as a critical friend. Imagine it is a year from now and this document has failed. Why? Shown as a bang.

FORMAT (follow exactly, or the diagram will not draw)

• Labels use only letters, numbers and spaces. No brackets, braces, quotes or symbols inside any label, even if the document has them.
• The only brackets are the shape markers shown above.
• Number each flag: g1, g2, c1, c2, r1, r2.
• Everything sits under root. Put nothing else inside the code block.
